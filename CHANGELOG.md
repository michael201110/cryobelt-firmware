# Changelog

## 0.1.0
- Initial CryoBelt Rev-A Arduino firmware skeleton.
- Added exact GPIO map from supplied KiCad netlist.
- Added BQ25895 safe-start / ESP-authorised charging path.
- Added SHT40, fan PWM/current, buttons, FUSB303 GPIO mode, and SK6805 support.
- Audio intentionally disabled because Rev-A netlist ties MAX98357A DIN/GPIO18 to final SK6805 DOUT.
